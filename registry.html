Implementation Registry

Self-attested NHID-Clinical implementations, with live NHID-CAS conformance badges.

This is a self-attestation list, not a certification. NHID-Clinical does not certify, audit, or warrant any vendor's implementation. A listing means the vendor ran the public conformance test suite (CTS) against their own integration and chose to publish the result. Badge scores update from each vendor's own live /v1/public/vendor/{id}/badge endpoint call — verify independently before relying on them for procurement decisions.

How to Get Listed

Run the conformance test suite against your integration, then complete the vendor trust questionnaire and open a pull request adding your entry to content/registry_entries.json. Each entry needs a vendor_id matching the one used when recording conformance results (see record_conformance_result() in nhid_event_store.py), so your badge renders live CAS data instead of the unknown/grey default.
