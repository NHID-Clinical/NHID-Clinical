Healthcare AI voice · provider–payer calls

AI callers should say they’re automated before they ask a payer for patient data.

NHID-Clinical is an open, testable control and evidence layer for provider-to-payer AI calls. It produces evidence, not a seal.

Start a shadow evaluation Read the specification

● Not a standard, a certification or a product. Observe-only in a shadow evaluation. Mapped to regulation, not certified against it.

The problem

Impersonation latency: the turns before the caller says it is a machine.

Impersonation latency is the time between the call connecting and the agent disclosing that it is automated: IL = t(disclosure) − t(connect), counted in conversational turns, with a target of zero. The harm is what moves inside that interval: protected data requested before the representative knows what is asking, which PDX-01 gates. A disclosure the representative interrupted before it was heard does not count; the clock keeps running.

A verified phone number does not tell you the caller is allowed to act for that provider. Telephony authenticates the number and identity systems authenticate the account; neither establishes that this caller may act for that organization on this call.

Impersonation latency is this project’s own term, not an established industry metric, defined so the interval can be measured instead of argued about. The definition in full.

The control layer

Five controls. Four act on the call; one records it.

Each control fires on something observable in the call, returns one decision, and writes a reason code into the trace. The canonical definitions are in the specification.

IDG-01

Identity Disclosure Gate

Disclose non-human identity before any PHI exchange. A disclosure counts only if it was heard.

Does not coverShows the agent said it’s automated, not that its claims are true.

PDX-01

Pre-Data Exchange Gate

No protected data until identity is disclosed.

Does not coverCloses the impersonation-latency window. Same-turn disclosure plus a request still fails.

DBC-01

Deceptive Behavior Check

No claim of human status or licensed-professional standing.

Does not coverJudged on the agent’s own words. Non-blocking (LOG_ONLY) and routed to human review.

EIT-01

Escalation Implementation Test

A clear human-handoff path, honored on request.

Does not coverA handoff counts only when it is recorded with a timestamp and an outcome.

ATR-01

Audit Trail Requirements

Every interaction produces a machine-readable trace.

Does not coverRecords what the other four decided. Changes no behavior.

Optional: DLG-01 delegated authority, off unless a deployment turns it on. How the opt-in gate works →

How a call is evaluated

One call in, a decision and a reason code out.

Every control reads the same turn on its own; nothing is chained. The most restrictive decision wins, and the audit trail records all of them. The engine is deterministic: the same input produces the same decision every time.

  1. InputCall traces you already holdRecordings or transcripts, one turn at a time.
  2. Adapterto_nhid_eventOne turn becomes one event in the NHID schema.
  3. Engineevaluate_allEvery control evaluates the same turn independently. DLG-01 first, if opted in.
  4. CompositeMost restrictive winsDENY_DATA > ESCALATE_HUMAN > DISCLOSE_IDENTITY > LOG_ONLY > CONTINUE_AI
  5. OutputPolicyDecisionPlus the ATR-01 audit trail, emitted as a FHIR R4 AuditEvent where enabled.

Scope

What it is, and what it is not.

is What it is

  • —An open specification
  • —Five testable controls
  • —A deterministic reference implementation
  • —Evidence per call: a decision, a reason code, a trace

is not What it is not

  • —A standard, a certification or a product
  • —In the live call path during a shadow evaluation
  • —A governor of the AI model itself: not its training, reasoning or outputs
  • —A detector of covert agents, or a check that the agent’s reported results are true
  • —Deployed in production anywhere

What it governs is one moment: when an automated caller acting for one organization crosses into another. Everything either organization does internally is out of scope.
