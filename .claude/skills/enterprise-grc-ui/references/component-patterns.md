# Component Patterns

## Loading Skeletons (Customer Portal style)
- Rounded rectangular cards
- Left-aligned square or circular avatar placeholder
- 2–4 horizontal text lines of varying widths
- Subtle background pulse animation
- Consistent spacing between cards

## Risk Workspace Cards
- Title + short description
- Status indicator (badge or pill)
- Key metric or risk score
- Action buttons aligned right or bottom
- Optional secondary metadata row

## Risk Heatmap / Posture Views
- Grid or matrix layout
- Color-coded cells (low / medium / high / critical)
- Clear axis labels
- Hover or click targets for detail
- Summary counts above the matrix

## Workspace Layout
- Left navigation or top bar
- Main content area with cards or tables
- Right sidebar for details or filters (optional)
- Clear page title and breadcrumbs
- Action bar for primary tasks

## Data Lists
- Consistent row height
- Left-aligned primary content
- Right-aligned metadata or actions
- Hover state that is subtle
- Pagination or infinite scroll indicators
