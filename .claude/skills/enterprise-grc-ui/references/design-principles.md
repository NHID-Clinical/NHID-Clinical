# Design Principles — ServiceNow Horizon Inspired

## Tone
Calm, operational, professional. Feels like trusted internal tooling used by compliance and risk teams. Avoid startup SaaS aesthetics, heavy gradients, glassmorphism, or flashy animations.

## Layout
- Generous whitespace
- Clear visual hierarchy
- 8pt grid discipline
- Auto-layout friendly (Figma-compatible)
- Consistent card and panel structures
- Mobile-responsive where relevant

## Color
- Neutral foundations (whites, soft grays, charcoal)
- Limited semantic accents for risk (green / amber / red)
- No decorative gradients
- High contrast for accessibility

## Typography
- Clean sans-serif for UI
- Strong hierarchy between titles, labels, and body
- Consistent tracking and line height

## Components
- Cards with clear boundaries
- Loading skeletons (placeholder blocks with subtle pulse)
- Status pills and badges
- Data tables and lists with clear scanning patterns
- Risk heatmaps and posture indicators
- Form controls that feel precise

## States
Always consider: default, hover, loading, empty, error, success.
