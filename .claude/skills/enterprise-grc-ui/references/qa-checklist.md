# QA Checklist

- [ ] Feels calm and operational, not consumer or startup
- [ ] Consistent spacing and alignment (8pt grid)
- [ ] Clear visual hierarchy
- [ ] Loading and empty states considered
- [ ] Risk colors used semantically only
- [ ] Readable at a glance
- [ ] Responsive or mobile-aware when relevant
- [ ] No unnecessary decoration or gradients
- [ ] Accessible contrast
- [ ] Components are reusable and clearly named
