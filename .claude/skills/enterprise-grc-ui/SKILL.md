# Enterprise GRC UI — ServiceNow-Inspired Components

Generate professional, operational interfaces for governance, risk, compliance, and customer portal experiences. Inspired by ServiceNow's Horizon design language, Customer Portal component library, and Risk Management Workspace templates.

Focus on calm, restrained, trustworthy UI that feels like internal enterprise tooling rather than consumer SaaS.

## Core Workflow

1. Identify the surface (Customer Portal, Risk Workspace, Governance Dashboard, Loading State).
2. Load design principles from `references/design-principles.md`.
3. Select or adapt patterns from `references/component-patterns.md`.
4. Generate clean HTML/CSS (or Figma-compatible descriptions) with proper hierarchy, spacing, and states.
5. Validate against the checklist in `references/qa-checklist.md`.

## When to Use

- User references ServiceNow, Horizon, Customer Portal, or Risk Management templates
- Requests for professional GRC, risk, compliance, or governance interfaces
- Loading skeletons, card layouts, workspace pages, or operational dashboards
- Needs enterprise-grade UI that avoids flashy gradients or consumer aesthetics

## References

- `references/design-principles.md` — Visual language, spacing, color, typography
- `references/component-patterns.md` — Cards, loading states, risk heatmaps, workspaces
- `references/qa-checklist.md` — Quality criteria
