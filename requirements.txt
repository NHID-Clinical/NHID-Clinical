# NHID-Clinical runtime and test dependencies.
#
# Every entry carries an upper bound at the next major. The floors were
# unbounded, so `pip install -r requirements.txt` resolved to whatever was
# latest on the day it ran: a breaking major release would have changed what
# CI and the Docker image execute with nothing failing to announce it, and the
# versions actually exercised had drifted far past the floors — openai two
# majors, cryptography nine, pytest and reportlab one each.
#
# The bound is a statement about what has been tested, not a guess about the
# future. `tests/test_dependency_contract.py` asserts the installed set
# satisfies these ranges, so a bound cannot drift out of step with what CI
# resolves. Raise a bound deliberately, after the suite passes on the new
# major.
#
# Verified clean: `pip-audit -r requirements.txt` reports no known
# vulnerabilities (2026-10-21).
