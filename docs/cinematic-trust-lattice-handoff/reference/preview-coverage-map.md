# NHID Clinical Cinematic Preview Coverage Map

## Shared visual rules

Every preview uses the approved visual language: a midnight-navy control space, electric cobalt and teal as semantic light, pale ice-blue evidence surfaces, thin technical grids, six-pixel corners, substantial editorial typography, very restrained elevation, and the five-layer Trust Lattice as the primary brand artifact. Public pages are intentionally light/dark hybrid rather than uniformly terminal-like; simulator pages retain an operational console surface.

## Page archetypes and route coverage

| Preview archetype | Routes represented | Primary visual purpose |
|---|---|---|
| Framework landing | `/framework/`, `/about.html`, `news.html`, `community.html` | Establish the public framework, narrative credibility, resource discovery, and contributor pathway. |
| Payer decision brief | `/for-payers.html` | Make shadow evaluation, decision evidence, and risk boundaries feel executive-ready and consequential. |
| Guided evaluation | `/shadow-evaluation-guide.html` | Turn a 90-day shadow evaluation into a clear staged operational journey. |
| Evidence center | `/evidence-pack.html`, `simulator-record.html` | Present trace-backed claims, evidence coverage, and evaluation record outcomes. |
| Formal specification | `/specification.html`, `/regulatory-alignment.html` | Support long-form norms, control definitions, standards mappings, and provenance. |
| Technical architecture | `/technical-stack.html`, `/interoperability.html` | Show the five-layer architecture, protocols, adapters, and integration evidence. |
| Developer portal | `/developers.html` | Blend developer documentation, API examples, SDK readiness, and technical credibility. |
| Roadmap | `/roadmap.html` | Show delivery horizons and public commitments without startup-style hype. |
| Simulator briefing | `/simulator.html`, `Simulator/index.html`, `zero-latency-module1-v2.html` | Frame real-time learning / detection scenarios with task focus and clear state. |
| Simulator validation | `zero-latency-module2.html`, `zero-latency-module3.html`, `zero-latency-module4.html` | Visualize passport inspection, compliance triage, and deployment safeguards. |
| Simulator command center | `zero-latency-dashboard.html`, `nhid-knowledge-base.html` | Provide fleet monitoring plus an operational knowledge resource. |
| AI Governance Map | `ai-governance-map.vercel.app` | Offer cross-framework navigation, maturity/risk filters, and controls comparison. |

The set will therefore show every supplied page through twelve distinct, reusable experiences rather than producing multiple nearly identical pages that hide the actual design-system decisions.
