NHID-Clinical v1.3 — Full Proposal

The complete open proposal document: the impersonation latency problem, four suggested behaviors for AI voice agents in healthcare payer–provider workflows, scope and rationale, and background context.

Download PDF → CC BY 4.0

v1.3 Core Specification

The normative reference: the five canonical controls (IDG-01, PDX-01, DBC-01, EIT-01, ATR-01) plus the supplemental bot‑to‑bot rule, the 18-case CTS conformance suite, and the scoring rubric used to evaluate an agent's behavioral trace.

Download PDF → CC BY 4.0

Evidence Pack

A procurement- and security-facing summary of the deterministic guarantees, real-corpus detection evidence, an anonymized failure trace, and the audit-readiness model behind the reference implementation. Everything is self-attested and open for community review.

Download PDF → CC BY 4.0

Operational Blueprint

A deployment-oriented walkthrough for engineering and compliance teams: integration tiers, adapter coverage, the CAS scoring model, and the FHIR AuditEvent export.

Download PDF → CC BY 4.0

Shadow Evaluation Guide

A practical guide for running NHID-Clinical's conformance checks alongside an existing voice AI deployment without changing production behavior — observe first, enforce later.

Download PDF → CC BY 4.0

v2 Technical Playbook

The reference implementation guide for NHID-Auth v2: Ed25519 agent passports, NPI binding, scoped delegation, and how it composes with the v1.3 behavioral baseline.
